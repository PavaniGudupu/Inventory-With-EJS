⭐ HOW THIS PAGINATION WORKS (Simple Overview)

Because you want:
✔ POST-based Pagination
✔ No query parameters
✔ No GET page URLs

So instead of using links like:
/products?page=3


You use:
<form method="POST"> ... </form>


Every pagination button submits a POST request with:
page
limit
inside hidden inputs.

Your backend reads:
const page = parseInt(req.body.page)
const limit = parseInt(req.body.limit)


and loads the correct page.

⭐ PART 1 — Auto-load the products page (openInventory.ejs)
<form id="openForm" action="/products" method="POST">
  <input type="hidden" name="page" value="1">
  <input type="hidden" name="limit" value="5">
</form>

<script>
  document.getElementById("openForm").submit();
</script>

📌 Explanation
1. <form id="openForm" action="/products" method="POST">

This defines a form.

It will send a POST request to /products.

Whenever this form is submitted, your backend route:

app.post("/products", ...)


gets triggered.

2. <input type="hidden" name="page" value="1">

Input is hidden → user cannot see it.

It sends: page = 1 (load page 1)

3. <input type="hidden" name="limit" value="5">

Sends limit = 5

Meaning: show 5 products per page.

4. JavaScript auto-submit
document.getElementById("openForm").submit();


This automatically submits the form as soon as the page loads.

So /products is opened using POST, without the user clicking anything.

⭐ PART 2 — Pagination Buttons inside productList.ejs

Your pagination UI uses <form> for each button.

🌟 PREVIOUS Button Section
<% if (pagination.previous) { %>
  <li class="page-item">
    <form action="/products" method="POST">
      <input type="hidden" name="page" value="<%= pagination.previous.page %>">
      <input type="hidden" name="limit" value="<%= pagination.previous.limit %>">
      <button class="page-link" type="submit">Previous</button>
    </form>
  </li>
<% } else { %>
  <li class="page-item disabled"><a class="page-link">Previous</a></li>
<% } %>

📌 Line-by-line Explanation
1. <% if (pagination.previous) { %>

Checks if a previous page exists.

Example:
If you're on page 3 → previous page = 2 (TRUE)
If on page 1 → previous page = NONE (FALSE)

2. <li class="page-item">

Bootstrap pagination styling.

3. <form action="/products" method="POST">

Clicking “Previous” sends POST /products.

4. Hidden inputs
<input type="hidden" name="page" value="<%= pagination.previous.page %>">
<input type="hidden" name="limit" value="<%= pagination.previous.limit %>">


These send:

page = previous page number

limit = existing limit

Example:

If you are on page 4, it sends:

page = 3
limit = 5

5. Submit Button
<button class="page-link" type="submit">Previous</button>


Styled as pagination link.

Clicking submits the form → loads previous page.

6. else block (if no previous page)
<li class="page-item disabled"><a class="page-link">Previous</a></li>


If you're on page 1, disable the Previous button.

✅ 1. What is this code?
<form id="openForm" action="/products" method="POST">
  <input type="hidden" name="page" value="1">
  <input type="hidden" name="limit" value="5">
</form>

<script>
  document.getElementById("openForm").submit();
</script>


This is auto-submit hidden form used to load the /products page using POST (NOT GET).

✅ 2. What is <form id="openForm">?
✔ It is NOT predefined

openForm is not a special HTML keyword.

It is your own custom ID name.

It works because you assign it using:

id="openForm"


Just like naming a variable.

You could even name it id="hello" or id="myForm" — it will still work if JS uses the same ID.

✅ 3. What does this form contain?

It contains TWO hidden inputs:

<input type="hidden" name="page" value="1">
<input type="hidden" name="limit" value="5">


These automatically send:

Field	Value
page	1
limit	5

➡ This means:
Load page 1 with 5 items per page.

✅ 4. Why are they hidden?

We don’t want to show a visible form.

We only want to send POST data automatically.

✅ 5. What does the JavaScript do?
document.getElementById("openForm").submit();

✔ It finds the form with ID openForm

Using getElementById.

✔ Then it automatically submits the form

Using .submit().

🚀 6. WHEN does this code run?
✔ Immediately when the page loads

As soon as the browser finishes reading the webpage, the <script> tag runs.

There is no button click, no event, nothing needed.

📌 7. What actually happens in the browser?
Step-by-Step Flow

1️⃣ User visits /openInventory
→ /openInventory redirects to /products

2️⃣ The browser loads the EJS page containing this form.

3️⃣ The form is hidden, so user does NOT see anything.

4️⃣ JavaScript runs immediately:

➡ It finds the form with id="openForm"
➡ It submits the form using .submit()

5️⃣ Browser sends a POST request to:

/products


With body:

page=1
limit=5


6️⃣ Your backend route handles it:

app.post("/products", async (req, res) => {
    const page = req.body.page;
    const limit = req.body.limit;
    ...
    res.render("productList.ejs", {...});
});


7️⃣ Finally, productList.ejs is rendered with pagination.

🎯 Why do we use this method?

Because:

✔ You want POST + pagination

But POST cannot be typed in browser URL (only GET).
So we use a hidden auto-submitting form.

✔ It behaves like:

Open /products page

But still send POST data

Without user clicking
